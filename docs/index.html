How a run works

Gather · Review · Check · Land

Each scheduled sweep runs these four steps for every PR, with a separate agent for each.

  1. 01

    Gather

    Reads the diff and every caller of the code it changes.

  2. 02

    Review

    Checks the change against a written rubric. Large PRs are split by area.

  3. 03

    Check

    Re-opens every quoted line and drops any finding that does not match the code.

  4. 04

    Land

    One review per PR. New repos hold it until you press and hold to post.

Features

Quiet until it has something for you.

  • Gist at a glance

    Approved, changes or skipped, and who the PR is from. Click a card for the reason.

  • Checked, not guessed

    A second pass re-opens every quoted line and drops findings that don’t match the code.

  • You stay in control

    New repos hold each review until you press and hold to post. Swipe to discard.

  • Runs on your schedule

    A 24-hour dial, weekdays only, pause for an hour or until tomorrow.

  • Your rules

    A Markdown file per repo with what your team cares about.

  • Your plan, your Mac

    Uses the Claude Code you already have. No account, no server, no telemetry.

Safety

Safe on public repos.

  • Claude may run only Glidepath’s own commands, each bound to the current run.
  • A strict filter rejects any other shell command.
  • Reads and writes stay inside the repo checkout and the run’s scratch folder.
  • GitHub tokens never reach the model.
  • Only collaborators’ PRs are reviewed. New repos hold each review as a draft until you post it.

The full design, with the adversarial test, is in docs/security.md.

Questions

Common questions.

Do I need an API key?

No. Glidepath runs the claude CLI you already use, on your Claude plan. An ANTHROPIC_API_KEY in your environment is passed through if you prefer API billing.

What leaves my Mac?

Only what Claude Code and gh already send: the PR diffs and code Claude reads go to Anthropic, and the reviews you post go to GitHub. Glidepath itself talks only to github.com (and its API, to check for updates). No analytics, no server.

Does it post as me?

Yes, through your gh login. New repos hold every review for you to post. posting = "comment" or "review" posts automatically.

Private repos?

Yes, anything your gh login can read.

How much does it use?

See What it costs. New setups start on Sonnet with five PRs a sweep.

Linux or Windows?

No, it’s a native Mac app. The glidepath CLI is macOS-only too (it uses launchd).
