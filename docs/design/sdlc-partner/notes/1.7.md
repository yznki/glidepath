# 1.7 build notes (Comments)

Intent: `../plan.md` "1.7: Comments", brain rows for 1.7 (council for threads; lessons from edits and pushback;
autopilot over disagree). Builds on 1.6 (`notes/1.6.md`).

## Data
- GraphQL adds: `reviews(last: 20) { nodes { id databaseId state body author { login } } }`,
  `comments(last: 30) { nodes { id databaseId body author { login } } }` (plain PR comments) → `OpenPR.comments:
  [PRComment {id, databaseId, author, body}]`, `ReviewInfo.body`, `ReviewInfo.databaseId`. Thread comments already
  carry databaseId/path/line.
- `Fingerprint.full(pr, me)` = CI part + sorted unresolved thread ids with their latest comment id + review ids with
  state + plain comment ids not by me. TendDecision uses it; the 1.6 `Fingerprint.ci` stays for tests/compat.
- `Threads` (Core/Threads.swift, pure):
  - `isBot(login)`: suffix `[bot]` or in `["coderabbitai", "copilot-pull-request-reviewer", "github-actions"]`.
  - `actionable(pr, me) -> [Ask]` where `Ask { id; kind: thread|review|comment; author; isBot; body; path; line;
    databaseId }`: unresolved threads whose last comment author != me; reviews with state CHANGES_REQUESTED and
    non-empty body by someone else, not already answered (id not in `TendPR.answered`); plain comments by others not in
    `answered`, skipping LGTM-only bodies (`lgtm`, `looks good`, `+1`, `approved`, `🚀`, `👍`, ≤ 3 words of those).
  - `ReplyGuard.check(text, author, slug, n) -> String?` refusal: > 600 chars; `@login` other than `author`;
    any `http(s)://` link not `https://github.com/<slug>/(pull/<n>/)?commits?/<hex>`.
- TendDecision: round when CI failed (as 1.6) OR `actionable` non-empty with a new full fingerprint. Class: urgent if
  approved and CI failed, else normal.

## Round
- Evidence gets `threads.md` (untrusted header): per Ask: id, kind, author (+bot), file:line, the code ±6 lines read
  from the worktree file at that line, every comment in the thread (author: body).
- tend.md gains a Threads section. result.json adds
  `threads: [{id, verdict: agree|disagree|unclear, reply, fixed: bool}]`. Rules: agree only when right and in scope;
  bot nitpick agree only if fix < 10 lines; disagree needs a concrete reason fitting the reply; else unclear.
  Replies are normal prose, ≤ 600 chars, no @mentions except the author, no links.
- One commit for CI + thread fixes. An empty diff with thread verdicts is not a PushGuard refusal: no commit, no push,
  replies only (agree+fixed with no commit → treat as unclear). After the push (or when nothing to push), apply each verdict:
  - agree+fixed → reply "Fixed in `<sha7>`: <reply>" then resolve (thread). Review/comment → issue comment reply.
  - agree without fix → treat as unclear.
  - disagree → actor via `Autopilot.actor(.disagree, …)`: `disagree = reply_resolve` → post + resolve;
    `draft` (default) → Your call with draft; autopilot → council.
  - unclear → Your call (no draft); autopilot → council.
  - Every posted text passes ReplyGuard; refused → Your call with the draft.
  - Held fix (until_approved): agreed replies wait in `TendHeld.replies` and post on `tend push`.
- Thread reply: GraphQL `addPullRequestReviewThreadReply(input:{pullRequestReviewThreadId, body})`; resolve:
  `resolveReviewThread(input:{threadId})`. Plain/review reply: `gh api repos/<slug>/issues/<n>/comments -f body=`.
- Re-request review: reviewers whose CHANGES_REQUESTED review was addressed this round (an agreed fix on their thread
  or review) → `gh api -X POST repos/<slug>/pulls/<n>/requested_reviewers -f "reviewers[]=<login>"` once each.
- `TendPR` adds `answered: [String]` (ask ids handled), `resolvedByUs: [String]` (thread ids), `calls: [YourCall]`
  (`YourCall {id (ask id), kind, author, quote (first 160 chars), draft: String?, at}`), `rereq: [String]`.
- NeedsItem kind `call` per YourCall ("Your call · <author>: "<quote>" · draft reply ready").
- Subcommands: `tend reply <slug> <n> <callId> [--text TEXT]` (posts text or the draft through ReplyGuard, resolves a
  thread, adds to answered, removes the call; the edit-vs-draft difference is a lesson signal), `tend dismiss <slug>
  <n> <callId>`.

## Council (Core/Council.swift pure parts + runner in CLI)
- When: autopilot on and a thread would otherwise be a Your call (disagree with draft, unclear), or a fix result with
  `confidence: low`. Cap `council_per_day` across all PRs (count in `tend/council.json` {date, count}); over cap → Your call.
- Judges: three parallel `claude -p --model sonnet --effort medium` sessions, no tools (`--tools ""`), no MCP,
  stream-json, `--max-budget-usd 1`; system = council text + lens + playbook; prompt = trimmed evidence (the ask,
  code context, proposed reply). Output last line JSON `{vote: "act"|"hold", reason, confidence, security: bool}` (system = `skill/glidepath/council.md`).
- `Council.outcome(votes) -> .unanimous(vote) | .split | .stop`: any `security` → stop; 3 same → unanimous; else split.
  Split → Opus chair (`--model opus --effort high`, prompt says "You are the chair") reads all three →
  `{decision: act|hold|unsure, line}`; unsure → stop. act → act; hold or stop → Your call (stop = hard stop, tower amber "Council could not settle").
- Recorded in the round RunState: `council: [CouncilRecord {topic, seats: [{lens, vote, reason}], chair: String?,
  outcome}]`; tower "Council 2–1, chair: post".

## Learning
- Lesson writer (Core/Lessons.swift prompt builder; CLI runner): `claude -p --model haiku --effort low --tools ""`
  with the signal; output one line ≤ 160 chars or `NONE`. Playbook.teach(source: "from your edit" | "pushback").
- Signals: `tend reply --text` differing from the draft (draft vs final); a thread in `resolvedByUs` that is
  unresolved again (reopened) → pushback with the thread's last comment.
