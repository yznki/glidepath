# 1.6 build design (Watch + CI)

Terse build notes. Source of truth for intent: `../plan.md` 1.6 + brain table. This file fixes names and shapes so
each brief can point here.

## Core (pure, tested)

### Config (`Core/Config.swift`)
- `enum TendPush: String, CaseIterable { case always; case untilApproved = "until_approved" }`
- `enum TendAdvisor: String, CaseIterable { case opus, off }`
- `struct TendConfig: Equatable` (table `[tend]`), safe parse defaults:
  `enabled=false, push=.untilApproved, roundsPerDay=5 (rounds_per_day, >0), triesPerHead=2 (tries_per_head, >0),
  maxFixLines=400 (max_fix_lines, >=0, 0=no cap), autopilot=false, advisor=.off, maxUsdPerSession=2
  (max_usd_per_session, whole dollars, >0; TOML reader has no floats), councilPerDay=10 (council_per_day, >=0),
  registries=["registry.npmjs.org","*.pypi.org","files.pythonhosted.org"], usageReserve=40 (usage_reserve, 0...90),
  quietHours=QuietHours.parse("22:00-07:00,sat,sun")! (quiet_hours, string), extras`.
- `Config.tend = TendConfig()`, `Config.claudeConfigDir: String? = nil` (top-level `claude_config_dir`, `~/` expanded,
  must be absolute). `RepoConfig.tend = false` (repo key `tend`).
- Render: `claude_config_dir` line when set; `[tend]` section (after `[limits]`) only when `tend != TendConfig()`,
  writing only non-default keys + extras; repo `tend = true` only when true. Unknown-key lists updated.
- Setup writers (`ConfigEditor`): `setTendEnabled(on)` — turning on also writes `advisor = "opus"` (recommended);
  `setTendPush`, `setTendRoundsPerDay`, `setAutopilot`, `setUsageReserve` (0...90), `setQuietHours(text)` (validates),
  `setRepoTend(slug,on)`, `setClaudeAccount(separate: Bool, home:)` — separate writes
  `claude_config_dir = "<home>/.config/glidepath/claude"` and `usage_reserve = 0`; same clears it and writes 40.

### UsageGuard (`Core/UsageGuard.swift`)
- `struct QuietHours: Equatable { start, end: ScheduleTime; days: Set<Weekday> }`. `parse("22:00-07:00,sat,sun")`,
  `text`, `contains(date, calendar)`: whole quiet day OR time in [start,end) (wraps midnight; start==end means none),
  `nextStart(after:, calendar)`: first 15-min step (≤8 days) where `contains`; nil if never.
- `struct UsageWindow: Codable, Equatable { type: String; utilization: Double; resetsAt: Date?; seen: Date }`
- `struct UsageState: Codable, Equatable { windows: [String: UsageWindow] }` → `stateDir/usage.json`;
  `load(paths)`, `save(paths)`, `record([UsageWindow])` (keyed by type, newest wins).
- `enum WorkClass: String, Codable { urgent, normal, deferred }`
- `enum SpendDecision: Equatable { now; wait(until: Date?, reason: String); stop(String) }`
- `UsageGuard.events(stream: String, now:) -> [UsageWindow]`: lines with `"type":"rate_limit_event"`, read
  `rate_limit_info.rateLimitType`, `.utilization` (0–1), `.resetsAt` (epoch seconds, optional).
- `UsageGuard.resultText(stream:) -> String?`: `"type":"result"` line's `result`.
- `UsageGuard.decide(cls, usage, reserve, quiet, now) -> SpendDecision`: live window = resetsAt>now, or no resetsAt
  and seen within window length (five_hour 5 h, seven_day 7 d, other 5 h). Over = utilization*100 >= 100-reserve.
  Deferred outside quiet → wait(nextStart, "Waiting for quiet hours"). Over: urgent → stop("Usage reserve reached ·
  resets HH:mm"), else wait(max resetsAt, "Paused for usage · resets HH:mm"). Else now.
  ponytail: no per-task estimate (tokens→utilization unknown); add once calibrated from History.
- Tokens from stream-json = `Transcript.tokens(lines:)` (assistant lines have the same shape).

### PushGuard (`Core/PushGuard.swift`)
- `struct ChangedFile: Equatable { path; status: String /*A M D*/; added: [String]; removed: Int }`
- `PushGuard.parse(diff: String) -> [ChangedFile]` from `git diff --cached -U0 --no-color --no-renames`.
- `PushGuard.refusal(_ files, maxLines) -> String?` in order: empty → "Empty change"; under `.github/`;
  name contains `.env` or ends `.pem`/`.key` → "Touches <path>"; deleted test file → "Deletes test file <path>";
  added line has `.skip(` `xit(` `xdescribe(` `@pytest.mark.skip` `t.Skip(` `it.todo(` → "Skips a test in <path>";
  maxLines>0 && Σ(added+removed) > maxLines → "<n> changed lines, over max_fix_lines <m>".
- `isTestPath`: `/test/ /tests/ __tests__ /spec/` segment, or name `*.test.* *.spec.* *_test.* test_*.py *Tests.swift`.

### Approach (`Core/Approach.swift`)
- GraphQL row `OpenPR: Codable, Equatable`: `n, title, body, url, author, isDraft, isFork, labels:[String],
  reviewDecision:String?, mergeable:String?, mergeStateStatus:String?, branch, head, base, additions, deletions,
  checks:[CheckState], threads:[ReviewThread], reviews:[ReviewInfo], requested:[String], updatedAt: Date?`.
- `CheckState { name; status: String /*COMPLETED…*/; conclusion: String?; url: String? }` (StatusContext maps
  state→conclusion, PENDING→status IN_PROGRESS).
- `ReviewThread { id; isResolved; comments:[ThreadComment] }`, `ThreadComment { id; databaseId:Int?; author; body;
  path:String?; line:Int? }`, `ReviewInfo { id; author; state }`.
- `ciStatus`: none (no checks) / pending (any status != COMPLETED) / failed (any conclusion in FAILURE, TIMED_OUT,
  CANCELLED, ACTION_REQUIRED, STARTUP_FAILURE, ERROR) / passed. `failedChecks`.
  ponytail: every check counts as required (isRequired needs a per-PR arg); fixing an optional red check is fine.
- `ApproachPhase: taxiing flying waiting holding cleared landed`.
- `Approach.marker(pr)` sequential: CI passed (or none) → 1; +approved, no CHANGES_REQUESTED, no unresolved thread → 2;
  +`mergeStateStatus == CLEAN` and not draft → 3. Landed = 4 (1.8).
- `Approach.phase(pr, state: TendPR?, working: Bool)`: draft→taxiing; held/stuck→holding; working or (CI failed and
  not off and not handsOff)→flying; marker 3→cleared; else waiting.
- `Approach.gates(pr,state) -> [Gate]` (CI, Threads, Approval, Ready) each `{name, state: ok|wait|work|none, detail, who}`.
- `Approach.label(...)`: "Ready to land" / "Fix held · approved, pushing cancels the approval" / "Stuck · <reason>" /
  "Glidepath fixing <check> · try k of N" / "Waiting on CI" / "Waiting on <reviewer>" / "Draft".
- `Approach.lanes(prs)`: child = base equals another open PR's branch. Chain from each root → one lane; lanes ordered by
  root number; `stackIndex` 1… bottom-up only when chain > 1.
- `ApproachPlane { slug, n, title, url, phase, marker, label, waitingOn, lane, stackIndex, off, gates, ci: String }`,
  `NeedsItem { id, slug, n, title, kind: held|stuck, detail }`,
  `ApproachSnapshot { updated, planes, needs, queued: Int, status: String?, working: String?, nextLook: Date? }`
  → `stateDir/tend/approach.json`.

### Tend state (`Core/Tend.swift`)
- `TendPR: Codable { slug, n, fingerprint?, roundsToday, roundsDate?, triesByHead, rerunsByHead, held: TendHeld?,
  stuck?, off, pendingRan:[String], pendingRanHead?, lastRound? }`, `TendHeld { commit, summary, at }`.
- `TendStore(paths)`: dir `stateDir/tend`, `file(slug,n)` = `<owner>-<name>-<n>.json`, `load/save/all/remove`,
  `approach` read/write, `appendTower(TowerLine)`, `tower(limit)`; `wtDir` = `tend/wt/<owner>-<name>-<n>`.
- `TowerLine: Codable { at: Date; slug; n; text; detail: String?; amber: Bool }` → `tend/tower.jsonl`.
- `Fingerprint.ci(pr)` = head + sorted `name=conclusion|status`.
- `TendLimits.rollDay(&s, today)`, `TendLimits.blocked(s, head, cfg) -> String?`.
- `TendDecision.decide(pr, state, me) -> .skip(String) | .idle | .round(WorkClass)`: fork→skip; label
  `glidepath:hands-off` or off→skip "hands off"; held→idle; CI pending/passed/none→idle; failed and fingerprint new →
  round(approved ? urgent : normal); else idle. New head clears `stuck`.
- `CIEvidence.ids(url) -> (run: Int, job: Int?)?` from `/actions/runs/<r>/job/<j>`;
  `CIEvidence.windows(log, before:60, after:20, cap:400)`: merged windows around `##[error]`; none → last 300 lines.

### Autopilot (`Core/Autopilot.swift`)
- `Actor: act | council | you`; `TendAction: pushFix(approved:) rerun giveUp flagPaths limitHit guardRefused`.
- Hard stops → you. rerun → act. pushFix(false) → act. pushFix(true) → autopilot or push==always ? act : you.

### Playbook (`Core/Playbook.swift`)
- `~/.config/glidepath/playbooks/<owner>-<name>.md`: `## Commands` lines ``- `cmd` · verified N× · yyyy-MM-dd``,
  `## Lessons` lines `- text · source · yyyy-MM-dd`. parse/render/verify(cmds,date)/teach(text,source,date)/
  remove(lesson)/cap(chars 8000: drop oldest lessons, then least-verified commands). Passed after the skill text as
  system prompt (stable prefix).

## CLI
- `glidepath tend` (launchd `dev.glidepath.tend`, `StartInterval 300`, log `~/Library/Logs/glidepath-tend.log`):
  `tend.lock` non-blocking; skip when paused, budget blocked, `tend.enabled` false, or hooks refuse. Per tended repo:
  GraphQL search `repo:o/n is:pr is:open author:<me>`; per PR → state, decision; rounds one at a time through
  `UsageGuard`; write approach.json + queue.json; remove state + worktree of PRs no longer open.
- `glidepath tend push|discard|retry|on|off owner/name N`, `glidepath teach owner/name "text"`.
- Round: limits → worktree (clone lock, `git worktree add --detach`, reset --hard origin/<branch>, clean -fd) →
  evidence.md (failed checks, job-log windows, title/body/diffstat, all marked untrusted) → session → result.json →
  apply (rerun once/head · giveup → stuck · fix → reset --soft head, add -A, PushGuard + flag_paths, commit, push or
  hold, rebase-once on reject) → record (TendPR, RunState kind "tend", tower line, playbook pendingRan).
- Session flags: `-p`, `--append-system-prompt <tend.md + playbook>`, `--model sonnet --effort medium`,
  `--advisor opus` (advisor on), `--max-budget-usd N`, `--output-format stream-json --verbose`,
  `--permission-mode dontAsk`, `--setting-sources user`, `--settings <sandbox json>`, `--strict-mcp-config
  --mcp-config {"mcpServers":{}}`, `--add-dir scratch`, `--allowedTools Read(//wt/**),Edit(//wt/**),Read(//scratch/**),
  Edit(//scratch/**),Bash`, `--disallowedTools WebFetch,WebSearch,Skill,Agent`.
  Sandbox JSON: `{"sandbox":{"enabled":true,"autoAllowBashIfSandboxed":true,"allowUnsandboxedCommands":false,
  "network":{"allowedDomains":registries},"filesystem":{"denyRead":["~/.config/gh","~/.ssh","~/.git-credentials",
  "~/Library/Keychains"]}}}`. Env: childEnvironment (+`CLAUDE_CONFIG_DIR` when set), no GH_CONFIG_DIR.
- Reviews: `--output-format stream-json --verbose` too; usage recorded; dry run prints `resultText`.
- `Claude.childEnvironment` passes `CLAUDE_CONFIG_DIR` from binding; Transcript reads `<claudeConfigDir>/projects`.
- Clone lock `stateDir/clone-<owner>-<name>.lock` (blocking flock) around clone sync and worktree git.

## CLI details (brief H2)

GraphQL (`gh api graphql -f query=Q -f q="repo:<slug> is:pr is:open author:<me>"`):

```graphql
query($q: String!) { search(query: $q, type: ISSUE, first: 30) { nodes { ... on PullRequest {
  number title body url isDraft isCrossRepository headRefName headRefOid baseRefName additions deletions
  mergeable mergeStateStatus reviewDecision updatedAt author { login }
  labels(first: 20) { nodes { name } }
  reviewRequests(first: 10) { nodes { requestedReviewer { ... on User { login } ... on Team { name } } } }
  reviews(last: 20) { nodes { id state author { login } } }
  reviewThreads(first: 50) { nodes { id isResolved comments(last: 10) { nodes { id databaseId body path line author { login } } } } }
  commits(last: 1) { nodes { commit { statusCheckRollup { contexts(first: 60) { nodes { __typename
    ... on CheckRun { name status conclusion detailsUrl }
    ... on StatusContext { context state targetUrl } } } } } } }
} } } }
```

- `Tender.parseSearch(Data) throws -> [OpenPR]` pure, fixture-tested.
- Worktree under clone lock (`RunLock.acquire(path, wait: true)`): `RepoClone.sync`; `git -C clone fetch --quiet origin
  +refs/heads/<b>:refs/remotes/origin/<b>` (and base); add `git -C clone worktree add --detach <wt> origin/<b>` or
  `reset --hard origin/<b>` + `clean -fd`. origin/<b> != pr.head → skip round (moved).
- All git that runs repo content uses `-c core.hooksPath=/dev/null` (repo hooks are untrusted, unsandboxed).
- Push: `git -C wt -c credential.helper= -c "credential.helper=!gh auth git-credential" push https://github.com/<slug>.git
  HEAD:refs/heads/<b>`; never force. Reject → fetch, `rebase origin/<b>`; conflict → `rebase --abort`, stuck.
- Evidence: failed check url → `CIEvidence.ids`; job id → `gh api repos/<slug>/actions/jobs/<job>/logs`; run only →
  `gh run view <run> -R <slug> --json jobs` failed jobs. Diffstat `git diff --stat origin/<base>...HEAD`.
- Rerun: `gh run rerun <run> --failed -R <slug>`.
- After push: `pendingRan`/`pendingRanHead`; a later check seeing that head green → `Playbook.verify`.
- Record: `RunState.tendAction` (`fixed|reran|stuck|held`), kind `tend`, target `pr:<slug>#<n>`, saved, never current.
  RunDigest tend titles: "Fixed CI on #n", "Reran <check> on #n", "Stuck on #n", "Fix held on #n"; lead = title,
  rest = summary.
- Tower text: "#n fixed <check> · pushed abc1234" (detail: `git show --stat --format= HEAD` + diff capped 40 lines),
  "#n reran <check>", "#n stuck · <reason>" (amber), "#n fix held · approved" (amber).
- Launchd: `Launchd.tendLabel = "dev.glidepath.tend"`, `Launchd.tendPlist(binary:path:logFile:)` StartInterval 300;
  `Paths.tendPlistFile`, `Paths.tendLogFile` (`~/Library/Logs/glidepath-tend.log`); `TendJob.install/remove(paths)`.
  Uninstall removes it.
- Reviews: append `--output-format stream-json --verbose`; record usage; dry run prints `resultText`.
- `CLAUDE_CONFIG_DIR`: child env for reviews and tend when `claude_config_dir` set; `Transcript` gets a `claudeDir`
  parameter (projects under it).

## App details (brief H3)

- `Snapshot.approach: ApproachSnapshot?`, `Snapshot.tower: [TowerLine]` (newest 30), `Snapshot.tendOn: Bool`,
  `Snapshot.tendRounds: [RunState]` (kind tend, today). Store reads `stateDir/tend/approach.json` + tower; watches
  `stateDir/tend`. New holding needs (id not seen before) → `Notifier.post(SweepNotice(title: "#n needs you",
  body: detail), runID: "tend-<id>-<detail hash>")`, quiet on first load.
- `WindowSection.approach` (title "Approach", symbol `scope`), between now and reviews. Sidebar shows
  "N in the air" (planes not landed) in small faint text instead of a count; `⌘` shortcut table follows the enum.
- `Window/Approach.swift`: `ApproachView(store)` + `ApproachModel: ObservableObject` (`opened: String?` plane id,
  `teach: String`, `expanded: Set<String>` tower lines). Layout per prototype: header (title 28 bold, status line
  "<working> · m:ss" or snapshot status or "Next look in N min", Autopilot pill toggling `ConfigEditor.setAutopilot`),
  chart card, then two columns (1.25fr / 1fr): Needs you (amber rows) and Tower (mono 11.5, time column 44 pt,
  click expands `detail`). Empty state (tending off): one line + "Turn on in Settings" button → Settings.
- `Window/ApproachChart.swift`: `ApproachChart(planes, reduceMotion, compact: Bool)` — `TimelineView(.animation)`
  (static when reduced or offscreen) + `Canvas`, coordinate space 1000×330 scaled to width (compact: 360×84).
  Fan: 5 lines from x=40 (y 40,100,165,230,290) to (880,165). Markers: dashed quad curves at x 300/520/720, mono
  labels "OUTER · CI", "MIDDLE · REVIEW", "INNER · READY". Runway rect (880,150,104,30), centre dashes, 4 lights at
  x 874, "MAIN". Plane x = [130, 300, 520, 720][marker] (taxiing 120); lane y = 60 + lane*55 (max 5 lanes, clamp),
  y eases toward 165 as x→880: y' = y + (165-y)*(x-40)/840. Stack followers trail 90 pt behind the leader, label
  "#n · k". Glyph = jet path (10,0)(-8,-6)(-4,0)(-8,6). flying: white, pulsing ring r 9→22 fading, dashed trail 170 pt
  behind moving; holding: amber, circling ellipse rx 34 ry 12 (5 s period), dashed amber ellipse; waiting: 0.8 opacity;
  taxiing: 0.35; cleared: white + amber "Ready to land". Labels: "#n" bold 12 above, status 11 below (amber when
  holding). Radar sweep: soft white vertical band moving left→right over 7 s. Reduced motion: no sweep, rings, trail,
  holding static amber. Tap a plane → `model.opened`. Legend bottom-left.
- Drawer (`ApproachDrawer`): 470 pt from the right edge over the section, `#09090C`, edge line, shadow. Title,
  "slug #n · <phase sentence>", ✕. Gates rows (dot ok/wait/work/none, name, detail, who). "Rounds today" from
  `tendRounds` for that PR (time, action title, tokens, summary). Teach field + button (writes `Playbook.teach` with
  source "you taught"), lessons list (playbook lessons + commands, newest 6). Toggle "Glidepath tends this PR · or add

  stuck → "Open PR" (NSWorkspace url) + "Try again" (`tend retry`). Run via the app's own binary like drafts do.
- Now: tend needs rows join Needs you (same row views). Popover: when tendOn, a block above the footer: mini chart
  (compact) + up to 3 needs strips + "Next look in N min". Menu bar label: small amber dot top-right when any plane
